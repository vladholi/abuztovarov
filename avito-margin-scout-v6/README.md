# Авито Маржа 6.0 — Chrome (Manifest V3)

## Новое в 6.0 — свой список автопоиска

В панели теперь есть раздел **«Мои товары для автопоиска»**:

1. Вставьте свои товары, **по одному в строке или через запятую**: например `Dyson Airwrap HS01`, `Makita DDF482`, `PlayStation 5 Slim`.
2. Нажмите **«+ Добавить в автопоиск»**. Названия появятся списком, дубли не добавляются. При необходимости можно удалить каждое название кнопкой × или очистить весь свой список.
3. Оставьте переключатель **«Искать только мои товары» выключенным**, если хотите искать свои модели **вместе** со встроенными: из 16 запросов за запуск до 8 мест приоритетно отводятся своим товарам. Если добавлено 1–8 своих моделей, каждая участвует в каждом запуске; если моделей больше, они чередуются с учётом прошлых запусков.
4. **Включите «Искать только мои товары»**, чтобы проверять только добавленные позиции (до 16 за запуск). Если список пуст, расширение подскажет добавить товары и не начнёт поиск.
5. Список (максимум 200 названий) и переключатель хранятся в `chrome.storage.local` и сохраняются после закрытия Chrome. Очистка истории поиска **не удаляет свой список**.
6. После добавления запускайте **«Автопоиск всего — новый набор»**. Кнопка **«Искать мой товар»** по-прежнему запускает разовый отдельный поиск, не меняя свой список.

Для более точного сравнения указывайте **конкретную модель и конфигурацию**, а не просто бренд: `Dyson Airwrap HS01`, а не `Dyson`.

**Оговорка:** добавление названия не гарантирует выгодных объявлений. При отсутствии четырёх сопоставимых цен оценка автоматически не строится. Расширение проверяет активные предложения, а не реальные завершённые продажи.

## Что исправлено

В версии 4.0 неизвестные русские названия городов **незаметно превращались в `/all`**, поэтому поиск мог уходить на всю Россию. Теперь это запрещено. **Город/регион обязателен и применяется в обоих режимах**, «Искать мой товар» и «Автопоиск всего».

1. В поле «Город или регион поиска» напишите, например, `Москва`, `Тула`, `Санкт-Петербург`, `Краснодарский край`, `Татарстан`. Поддерживается много городов и несколько распространённых регионов.
2. Если место не распознано, откройте сайт Авито, выберите нужную географию в стандартном селекторе города/региона, **скопируйте URL из адресной строки** (например, `https://www.avito.ru/tula?q=iphone`) и вставьте его в поле. Программа возьмёт первый сегмент URL; для неизвестных географических областей может понадобиться указание более конкретного города. Если Авито автоматически открывает другой регион, поиск будет остановлен.
3. По всей России можно искать только при **явном** вводе `Вся Россия`.
4. Для города в ссылку поиска дополнительно ставится `radius=0`; поскольку площадка может всё равно возвращать объявления из других регионов, программа **проверяет географию каждой карточки по URL объявления**. Для широкой области принимает объявления с подтверждённой принадлежностью к региону: из известных городов региона или с указанным регионом в карточке. Если нельзя проверить, **исключает** объявление. Это лучше, чем показать покупку за сотни километров, но может скрыть некоторые местные предложения.
5. При изменении региона в поле старые результаты **не показываются**. Запустите поиск заново. В карточках, истории и CSV теперь виден выбранный регион.

**Важная оговорка:** список региональных городов неполный. При поиске по области часть настоящих местных объявлений может не попасть в выдачу. Для точного самовывоза лучше вводить конкретный город. Работа текущей географии Авито **не проверялась на живом сайте**; при изменении структуры ссылок или карточек может потребоваться настройка.

## Установка / обновление

1. Распакуйте архив в отдельную постоянную папку.
2. Откройте `chrome://extensions`, включите «Режим разработчика» и нажмите «Загрузить распакованное расширение».
3. Выберите папку `avito-margin-scout-v6`, внутри которой находятся `manifest.json`, `dashboard.html` и другие файлы.
4. Если предыдущая версия установлена отдельно, отключите её, чтобы не перепутать кнопки. При установке как нового расширения старое хранилище не переносится; чтобы сохранить историю, обновляйте **ту же** папку существующего расширения и нажмите «Обновить».

## Поиск и экономика

- **Ручной поиск:** 4 формулировки по указанному названию; при желании задайте свою цену перепродажи.
- **Автопоиск всего:** до 16 запросов за запуск по встроенным 72 и собственным (до 200) моделям. Пользовательские модели получают до 8 приоритетных слотов либо могут стать единственным источником при переключении «Только мои». Состояние очереди сохраняется в Chrome.
- **Результаты:** фильтр строгой положительной прибыли, минимальной прибыли/маржи и верхней цены покупки. Автоматическая цена продажи — ориентир по ценам **активных** сопоставимых объявлений, а не подтверждённая цена совершённых сделок.
- **Уведомления:** после завершения запуска Chrome уведомляет максимум о 3 впервые обнаруженных подходящих предложениях. Постоянного фонового поиска и отправки на телефон нет.
- **CSV:** экспортируются только отфильтрованные объявления текущего региона.

## Ограничения

Товар с хорошей предполагаемой маржой может оказаться неликвидным, сломанным, поддельным или иметь дополнительные расходы. Оценки не являются гарантией прибыли. Сайт может менять формат URL и разметку объявлений или ограничивать автоматизированные обращения. Расширение не обходит защиту/капчи. Работает в настольном Chrome. Нет реальной статистики продаж и не подтверждён рейтинг спроса.

## Локальные тесты

```bash
node tests.js
```

Тесты проверяют добавление личных запросов, отсутствие дублей, ротацию встроенных и личных моделей, режим «Только мои», фильтр маржи, URL поиска города/региона, запрет неявного `/all`, остановку при неверной географии и исключение объявлений чужих регионов. **Не заменяют проверку на настоящем Авито.**
