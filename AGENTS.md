# Правила работы с Avito Margin Scout

Область действия — весь репозиторий. Рабочий продукт находится в `avito-margin-scout-v6/`. Это расширение Chrome Manifest V3 на JavaScript. Точка входа для разработчика — [README](avito-margin-scout-v6/README.md).

## Процесс

- Общайся на русском. Для разработчика с опытом DevOps объясняй нетривиальные решения на примерах из текущего изменения.
- До правок прочитай затронутые файлы и проверь рабочее дерево. Укажи короткий план, модули, риски, допущения и способ проверки. Для небольших изолированных правок продолжай после плана.
- Для изменений архитектуры, схемы данных, публичного API, зависимостей, безопасности, деплоя, CI/CD или поведения в продакшене получи согласование плана до редактирования.
- Сохраняй пользовательские изменения. Согласуй разрушительные операции. Исключи ключи, токены, приватные конфиги и реальные профили браузера из вывода, коммитов и архива.
- Ограничь diff задачей. Разделяй проверки модели и географии, работу браузерной панели и сборку. Обрабатывай ошибки чтения и записи явно. Учитывай данные предыдущей версии в `chrome.storage.local`.
- Описывай изменения для пользователя в README, изменения эксплуатации — в [инструкции выпуска](docs/release.md). Добавляя файл, нужный при исполнении, проверь его включение в ZIP.

## Набор навыков

| Навык Codex | Когда применять | Результат |
| --- | --- | --- |
| `review` | Ревью PR или ветки перед слиянием | Замечания с местом в коде, условием возникновения и последствием |
| `blast-radius` | Меняется сравнение моделей, фильтр региона, формат сохранённых данных или экспорт | Проверка поведения зависимого сценария на реальном коде |
| `playwright` | Нужна автоматизация браузерного сценария панели | Проверка пользовательского действия в отдельном тестовом профиле |

Навыки относятся к среде разработки. Для выполнения расширения достаточно файлов из релизного ZIP.

## Проверка и отчёт

Из корня запусти `node avito-margin-scout-v6/tests.js`, `node --test tests/dashboard-export.cjs` и `python scripts/package_extension.py`. Проверь синтаксис изменённых JS через `node --check`. Для изменений Chrome API, селекторов и установки пройди браузерные сценарии в инструкции выпуска.

В финальном отчёте дай резюме, список файлов, проверки, разделы «Что было сделано и почему», «DevOps / production notes», риски и дальнейшие задачи. Различай выполненные проверки и запланированные. Для пропущенных укажи команду или сценарий, причину и ожидаемый результат.
